# Attribution and component notices

The [README credits](README.md#credits) identify the project's contributors and
upstream research, including gsret's original disassembly, FutureFractal's
annotations and headers, and SAT-R/sa2's m4a reconstruction. Preserve these credits
and any file-level notices when contributing or moving source.

The build uses the separately maintained camelot-gcc and pret/agbcc-derived
compiler sources. Those repositories carry their own component notices; installed
compiler binaries are not part of this source repository. The optional asm-differ
installation likewise retains its upstream notices.

This index does not introduce a project-wide license or replace component notices.
A project-wide license has not been selected in this document. Any such decision
and review of imported components remains with the maintainers. ROMs and extracted
build assets are not contribution artifacts; see [CONTRIBUTING.md](CONTRIBUTING.md).
